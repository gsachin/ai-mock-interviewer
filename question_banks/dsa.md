# Data Structures and Algorithms Question Bank

## Sliding window technique

When does the sliding window technique apply and how do fixed and variable
window variants differ? Expected points: contiguous subarray or substring
problems, two-pointer window expansion and contraction, O(n) time versus
naive quadratic, and examples like maximum sum of size k.

## Binary search template

Write and explain a binary search template that avoids off-by-one errors.
Expected points: inclusive versus exclusive bounds, the loop invariant,
midpoint overflow, and how the same template adapts to searching rotated
sorted arrays.

## Design an LRU cache

Design an LRU cache with O(1) get and put. Expected points: hash map plus
doubly linked list, head and tail sentinels, eviction policy on capacity,
and why order maintenance needs the linked structure.

## Tree traversals

Compare inorder, preorder, and postorder traversals and their iterative
implementations. Expected points: recursion versus explicit stacks, when
each order matters for binary search trees, and time and space complexity.
